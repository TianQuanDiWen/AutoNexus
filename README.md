# 🚀 AutoNexus - 自动化任务批量调度服务端

> 极轻量、低资源占用、静默常驻在 Windows 后台的自动化调度总控服务。  
> 深度适配并串行调度基于 **Go + MaaFramework** 的自研游戏自动化项目（如 `MaDOAXVV`），提供手机可控的响应式 Web 界面与内核级进程生命周期保障。

---

## 一、 项目定位与核心愿景

- **产品形态**：一个**极轻量、低资源占用、静默常驻在 Windows 后台**的自动化调度总控服务。
- **操作方式**：提供**局域网响应式 Web 页面**，手机、平板或局域网设备打开浏览器即可查看当前进度、调整队列顺序、一键启动/急停、监看控制台实时日志。
- **阶段目标**：
  - **Phase 1（当前 MVP）**：深度适配并串行调度现有的两款自研自动化项目（基于 Go + MaaFramework 体系）；
  - **Phase 2**：支持多账号配置轮转，提供任务历史记录与错误自愈；
  - **Phase 3**：对外暴露标准 REST API / MCP，预留给 AI 作为智能监工（Supervisor）进行多模态画面判断与控制；支持接入其他第三方游戏自动化脚本。

## 二、 核心技术栈选型

| 模块 | 技术选型 | 选用理由 |
| :--- | :--- | :--- |
| **主程序后端** | **Go (Golang 1.22+)** | 静态单二进制文件交付（约 10MB），启动仅需毫秒级，常驻内存仅 **15MB~30MB**；原生 Goroutine/Channel 天生适合高并发管道与任务调度；Win32 底层系统调用稳定。 |
| **前端界面** | **原生原生 HTML5 + CSS3 + 原生 JavaScript (零编译依赖)** | 手机端优先（Mobile-first）深色响应式控制台；无 Node.js、无 npm 构建链，直接通过 Go 原生 `//go:embed` **打包进单 exe**，极简轻量、零外部环境依赖。 |
| **通信机制** | **REST API + WebSocket** | 页面与服务通过 REST API 控制；控制台输出通过 WebSocket 毫秒级流式推送到轻量自研虚拟终端（内置 1200 行防爆环形缓冲与自动滚屏）。 |
| **进程与安全性**| **Win32 Job Object** | 通过 `windows.CreateJobObject` 与 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` 实现内核级绑定，杜绝孤儿/幽灵游戏进程驻留后台。 |

## 四、 针对自研项目（Go + MaaFramework）的落地考量

1. **坚持“纯无头（Headless）”调度**：
   - **不**在后台拉起带界面的外壳（避免 WebView2 额外吃掉 300MB+ 内存和在屏幕上闪烁抢焦点）；
   - **直接**由调度服务调用编译好的 Agent 命令行模式运行对应 pipeline（例如 `madoaxvv-agent.exe run --task ...`）。
2. **游戏进程排他与环境清理**：
   - 前一个任务完成后，调度器显式检查对应游戏进程是否已退出；
   - 若未退出则利用进程管家强杀；
   - 任务之间设置 **5~10 秒系统冷却缓冲**，确保显存和 Windows 句柄释放完毕后再拉起下一个游戏。

---

## 五、 核心避坑设计法则

1. **必须绑定 Windows Job Object（血泪经验）**：
   - 普通子进程在服务异常退出或被强杀时会变成后台幽灵，死死占用游戏端口和显存。利用 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` 让 Windows 操作系统内核做清理兜底。
2. **stdout 管道独立协程消费**：
   - 子进程输出日志时，主程序必须用独立 `go func()` 异步持续读取并清空管道缓冲区，否则日志填满缓冲池后子进程会彻底挂起死锁。
3. **日志节流与广播池设计**：
   - 内部实现类似 `Hub/LogBroadcaster` 的带锁环形缓冲池；给局域网推流时做轻量批处理或非阻塞分发，避免高频 I/O 导致浏览器卡顿或 Go 进程阻塞。

## 七、 编译与运行模式

AutoNexus 采用纯 Go 实现，**全程无需 CGO、无需安装 gcc/MinGW**：

### 1. 桌面客户端模式 (默认推荐，无控制台黑框)
```powershell
go build -ldflags="-H windowsgui -s -w" -o autonexus.exe ./cmd/autonexus
```
- 双击运行直接弹出独立原生桌面窗口，右下角托盘常驻，单二进制体积仅 **~7MB**。
- 点右上角 **“×”** 自动最小化至系统托盘，后台任务与局域网服务不受影响；单击托盘图标毫秒级唤出。
- 右键托盘图标可快速：**显示主界面**、**复制局域网手机访问地址**、**一键急停所有任务**、**彻底退出**。

### 2. 无头纯后台模式 (适用于远程服务器或无桌面环境)
```powershell
.\autonexus.exe --no-ui
```
- 不创建 GUI 窗口与托盘图标，仅在后台启动 HTTP 与 WebSocket 调度服务。
